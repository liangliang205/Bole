# 已知限制与延期工作（兑现"无夸大"）

> 原则：**能跑通的说清楚怎么跑，没做的明确说没做，做了一半的说明边界。** 本文件与代码、报告、演示脚本保持一致。

## 1. 功能边界（P0 明确不做）

| 项 | 现状 | 原因 / 计划 |
|---|---|---|
| 真实邮箱 IMAP/Exchange | 未实现；默认使用 `data/inbox/*.eml` mock 邮箱 | P0 先稳定筛选闭环；MCP 客户端接口已抽象，P1 替换 `HireboxClient` 的 MCP server 即可，接口不变 |
| Web 控制台 | 未实现；提供 CLI + 静态 HTML 报告 | P1 可接 Mastra Playground 或轻量只读面板；机制层已与展示层解耦 |
| 检查点恢复 | **批次粒度**：未提交任务标记 aborted，简历重置后重跑 | 事务级恢复（按任务/事件重放）在 P1；当前已提交产物复用，不会重复计费 |
| 多租户 / 权限系统 | 未实现 | 不属于筛选闭环必需；台账 schema 预留 `job_id` 隔离 |
| 自动发 offer / 拒信 | 明确不做 | 平台只出建议；不可逆决策必须由人完成 |
| 面试安排、薪资核算、跨语言翻译 | 明确不做 | 见需求文档 1.4 范围外 |
| 需求中途变更（SRS S3） | 未实现 | 需新建任务重跑；偏好记忆（FR-F1）列入 P1 |

## 2. 数据与格式限制

| 项 | 现状 | 影响 |
|---|---|---|
| 旧版 `.doc` | 拒绝解析，进入失败明细 | 黄金集 R19 即此样本；提示用户另存为 docx |
| PDF | 仅文本层尽力提取（FlateDecode + Tj/TJ），扫描件与 CID 字体中文 PDF 可能失败 | 失败会如实出现，不会伪造内容 |
| 表格/多栏排版 | 归一化后压平为文本，可能丢失版式 | 解析字段的 quote 仍可定位到原文连续片段 |
| 中文编码 | UTF-8 / GBK 探测 | 其他编码（Big5 等）可能乱码 |
| 简历去重 | 同 job 内、按附件哈希 + 姓名/手机/邮箱指纹 | 跨岗位重复投递不抑制；身份信息缺失时退化为正文哈希，可能漏判 |
| 邮箱附件 | 仅取第一份附件；无附件时用正文（≥50 字符）兜底 | 多附件简历只处理第一份 |

## 3. 模型与评测限制

- **mock 不等于真实 LLM**：mock 是确定性规则模拟（关键词、规模标记、模板理由），用于离线复现和机制验证；它不能代表 DeepSeek 的真实语义质量。真实效果需配置 API Key 后用同一黄金集重跑。
- **模型非确定性**：真实模式温度=0，但仍可能有 ±1 分波动；黄金集基线是按 mock 模式冻结的，真实模式回归需另建基线。
- **LLM-as-judge 未接入**：评测采用黄金集端到端断言 + 人工抽样，未实现 Mastra Evals 的五维 LLM 评分；P1 计划接入。
- **证据"支持度"判断**：规则能拦截显式拔高（"主导"无对应原文）与低重合度引用，但深层语义支持仍依赖模型；监军也可能误判。
- **公平性审查**：词表 + 语义复核，不构成法律意见；对隐性偏见（如"稳定性"话术）覆盖有限。终稿必须 HR 签字（HITL-2 即此设计）。
- **简历真实性**：只能核验"原文是否存在该表述"，无法核验候选人自述业绩的真实性；面试建议会提示验证口径。

## 4. 调度与工程限制

- **单机 SQLite**：不支持多机分布式调度；写入并发受 SQLite 限制。P1 可换 Postgres（表结构已兼容）。
- **容量池拒绝不排队**：高负载下会出现较多 refusal，依赖编排层有界重试吸收；极端情况（超过 200 次重试）任务会失败，不会无限等待。
- **批流动内存态**：在途批与 Worker 状态在进程内；崩溃恢复走"批次重跑"，不是断点续传。
- **提示词/配置热更新**：修改 `config/` 后需要新起进程；注册表指纹会写入每次运行，便于区分版本。
- **未直接依赖 Mastra**：为保证离线可复现与机制层可控，编排/调度/验证自研；模型与结构化输出保留了替换接缝。详见架构文档第 9 节。
- **未做压测**：`bole bench` 是调度层微基准（模拟时延），不是 300 份简历的真实端到端压测；真实吞吐受模型网关限流影响。
- **可访问性/国际化**：CLI 与报告为中文；HTML 报告未做无障碍适配。

## 5. P1/P2 路线

| 优先级 | 工作 | 预期收益 |
|---|---|---|
| P1 | IMAP/Exchange MCP server（接口不变） | 真实邮箱接入 |
| P1 | 事务级检查点恢复（按事件重放未提交任务） | 中断续跑更细粒度 |
| P1 | 真实模型黄金集基线 + Mastra Evals 五维评测 | 量化模型质量 |
| P1 | 需求变更与偏好记忆（FR-F1/F2） | 招聘中途调整 |
| P2 | Web 控制台 / Mastra Playground 只读面板 | 演示与运营 |
| P2 | 证据链可点击回跳（HTML 原文高亮 + 定位） | 更好的人机审阅 |
| P2 | 按简历复杂度分配 effort（简单 flash、疑难多子代） | 成本/质量优化 |
| P2 | Postgres + 多机调度 | 规模化 |
