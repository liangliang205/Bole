# 岗位画像库（JD Corpus）

## Java 后端工程师（金融科技方向）

- 年限：3-6 年 Java 服务端经验，经历连续。
- 硬性：Java 基础扎实，熟悉 Spring Boot / Spring Cloud、MySQL、Redis；理解消息队列（Kafka/RocketMQ）。
- 加分：支付、清结算、风控、账务等金融业务经验；参与过高并发系统设计与性能优化。
- 团队：有 3 人以上小组负责经验优先。
- 排除：仅外包驻场且无核心系统 owner 经验者需降级评估。

## 高级 Java 后端工程师（互联网交易方向）

- 年限：5-8 年，至少两段完整系统建设经历。
- 硬性：微服务拆分、分布式事务、缓存与消息中间件；有容量规划与稳定性治理经验。
- 加分：秒杀/大促/交易链路优化；有量化结果（QPS、P99、可用性）。
- 注意：不以"大厂背景"作为唯一加分，需看具体职责与产出。

## 数据平台工程师

- 年限：3-6 年，Java/Python/Go 至少精通一门。
- 硬性：离线与实时数仓、Spark/Flink、SQL 优化。
- 加分：数据治理、指标平台、血缘系统落地经验。

## 前端工程师（中后台方向）

- 年限：2-5 年，React/Vue 至少一项精通。
- 硬性：TypeScript、工程化（构建、监控、灰度）、性能优化。
- 加分：低代码平台、组件库建设经验。

## 评分卡通用原则

- 维度数量控制在 3-6 个，权重合计 100。
- 每个维度必须有 1/3/5 分锚点，锚点描述可观察、可验证。
- 与岗位胜任力无关的受保护属性（性别、年龄、婚育、地域、民族等）不得进入评分卡。
- 分数必须可由简历证据支撑；无证据的维度按"不确定"降级，而不是给中间分。
